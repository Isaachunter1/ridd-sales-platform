# Contributing

Everything about working in this repo — layout, recipes, the rules every change respects, how deploys happen — is in **`CLAUDE.md`**. It is written for Claude and for people alike. `MIGRATION.md` says what is in flight.

The short version: branch from `main`, run `npm run check` before every push, open a PR, test on the Netlify deploy preview on a phone and a desktop, and let Isaac merge. `main` is production.
